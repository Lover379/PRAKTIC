# Дашборд мониторинга пожаров в Иркутской области (2005)

Интерактивный веб-дашборд для визуализации лесных пожаров и анализа вегетационных индексов в Сибирском регионе.

## 🛠 Стек технологий
* Фронтенд: HTML5, CSS3 (Flexbox), JavaScript (ES6+)
* Сборщик: Vite
* ГИС и Графика: Plotly.js-dist-min

## 🌍 Функционал карты
* Реальные контуры: Отрисовка точных границ выгоревших площадей (`MultiPolygon`) через GeoJSON-слои.
* Гибридный спутник: Подложка высокого разрешения Esri World Imagery с наложением прозрачного слоя названий городов и дорог.
* Переключение режимов: Кнопка «на лету» меняет подложку со спутника на темную аналитическую карту (`carto-darkmatter`).
* Интерактивные подсказки: Клик по полигону выводит плашку с ID пожара и метаданными.
